## 香港这条线，官网自己写了「三网绕路」

HK 套餐页面顶部那句话很直白：三网绕路，可用性高，联通优秀。商家主动承认绕路，比藏着掖着好判断。

这意味着它不适合对延迟敏感的业务，比如实时对战、低延迟 API 网关。适合的是需要香港 IP、又不指望大陆访问有多快的场景：跨境店铺后台、海外社媒运营、给联通用户做中转。联通方向是这条线里表现最好的，电信和移动走的是绕路。

和 raksmart 那台香港 $2.99/月的机器放一起看，差价不在机房里，在参数上：一台是 1 核 / 1GB / 50G HDD / 1Mbps，一台是 2 核 / 1GB / 20G NVMe / 300Mbps / 2TB。前者便宜，但 1Mbps 带宽在 2026 年基本只能跑文本页；后者贵出数倍，换来的是 300Mbps 和 NVMe。哪个划算取决于你要传多少数据，不是取决于谁标价低。

## 原生 IP 是另一条产品线，促销价买不到

台湾和英国这两条线卖的不是配置，是 IP 属性。

台湾那台在台北，上游是 Akari Networks，E5-2683v4 处理器，KVM 虚拟化，默认开 BBR。第三方测评的结论是：台湾原生 IP，可解锁台湾 TikTok、ChatGPT、Claude、Gemini、Netflix、Disney+ 和 Steam 货币；Geekbench 6 单核 512 分，跑一般任务够用；延迟偏高、走绕路，电信和联通走中转效果较好，移动可以直连。

英国那台在伦敦，上游 ZGX US LLC，Gold 6138 处理器，KVM，不支持 IPv6。测评结论是：英国原生 IP，可解锁英国 TikTok、ChatGPT、Netflix、Disney+、Claude，解不了 Gemini；实测那台实例不显示住宅属性；性能偏弱、延迟高，部分路由绕美国。

两台都是 512M 内存。这个配置跑 Linux 加代理或自动化脚本没问题，装 Windows 会很吃力。买之前想清楚用途，别指望它当通用建站机。

支付方式上，信用卡、PayPal、支付宝都支持，套餐页标注 30 天退款保证。对第一次用这家的人来说，30 天足够验证 IP 能不能解锁你要的服务。
